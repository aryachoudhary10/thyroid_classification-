# Paper figures — provenance and reproduction

Every number in every figure here is read from a real result file under
`../kaggle_jobs/**` (produced by actual training/evaluation runs on Kaggle) or
computed live from real checkpoints on this machine. Nothing is estimated,
interpolated, or invented. `data.py` hardcodes the exact path to each source
file and raises loudly if one is missing rather than silently substituting a
different file.

## Reproduce everything

```bash
cd paper_figures
python make_all.py
```

Outputs land in `output/png/` (300 dpi), `output/pdf/` (vector), `output/svg/`
(vector), and `output/captions/*.txt` (one caption per figure, generated by
the same script that made the figure — the numbers in each caption are
computed inline, not typed by hand).

## What each figure is, and where its numbers come from

| Figure | Content | Source data |
|---|---|---|
| 1 | Dataset composition: class balance, TI-RADS, frames/patient, TN5000 splits | `manifest.csv`, TN5000 `tn5000_manifest.csv` |
| 2 | ROC/PR curves, bootstrap CI, confusion matrices (RCAF/MR-MIL/DER-MIL) | `test_predictions.csv` per model (ResNet-50) |
| 3 | Ablation ladder (lesion-only → MR-MIL → DER-MIL) + fusion-rule probe | `ablation_convnexttiny.csv`, linear-fusion predictions |
| 4 | Reliability mechanism: evidence ablation, R-vs-influence, per-region correlation | `reliability_influence.json`, raw per-token dump, `evidence_ablation.csv` |
| 5 | Calibration: reliability diagrams, ECE before/after prior-shift correction | raw `p_raw`/`p_cal`, `calibration_table.csv` |
| 6 | Robustness: mask degradation, frame removal, mask-shuffle, permutation invariance | `mask_quality.csv`, `frame_removal.csv`, `shortcut.csv`, `permutation_invariance.json` |
| 7 | Statistical uncertainty: per-fold OOF AUC, bootstrap CI, DeLong tests | `oof.csv` per fold, `test_predictions.csv` |
| 8 | TN5000 external validation: full arm ladder + measured run-to-run variance | recovered arm-ladder table, raw TN5000 predictions |
| 9 | Computational cost: exact params (from checkpoints), FLOPs/latency (measured live) | `*.pt` checkpoints, `torch.profiler` on this machine |
| 10 | Architecture schematic | diagram of the actual code (`src/models/*.py`), not measured data |
| 11 | Error analysis: TP/TN/FP/FN, false-negative rate by TI-RADS | `test_predictions.csv` joined to `manifest.csv` |

## What is deliberately NOT here

No raw ThyroidXL or TN5000 pixel data, saved attention weights, or model
embeddings exist anywhere in this local environment — every training and
evaluation run happened on Kaggle, and only result tables (CSV/JSON) and a
handful of checkpoints were ever fetched back. As a result, the following
requested categories are **not producible from what exists locally** and are
not faked with placeholders:

- Representative ultrasound images / preprocessing / ROI crops
- Attention-MIL visualisation overlaid on actual frames
- Grad-CAM for correct/incorrect predictions
- Feature-space t-SNE / UMAP / PCA of patient or frame embeddings

Figure 4(d) substitutes the closest thing that *is* real and available: the
model's own per-frame reliability score R for one real test patient, plotted
directly from the raw per-token dump — not an attention overlay on an image,
but a genuine per-frame importance signal for a genuine patient.

Unlocking the four categories above would need one additional Kaggle
inference pass that saves small artefacts (rendered Grad-CAM PNGs, attention
alphas, patient/frame embedding vectors, a handful of representative crops) —
that is a scoped, cheap CPU/GPU job, not a retraining run, but it has not been
launched.

## A correction made during construction

An early draft of Figure 6(b)'s caption stated the removal test backwards.
The real numbers (`frame_removal.csv`) show removing the frame DER-MIL scores
as *most* reliable costs the *most* ranking performance (ROC-AUC 0.9758 after
removal, vs 0.9839 for removing the *least* reliable frame) — the correct
direction for an informative ranking. The caption was rewritten to match the
data before this README was written.
