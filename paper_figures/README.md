# Paper figures — ConvNeXt-Tiny (primary) + ResNet-50 (supplementary)

Every number in every figure here is read from a real result file under
`../kaggle_jobs/**` (produced by actual training/evaluation runs on Kaggle) or
computed live from real model instantiations / checkpoints on this machine.
Nothing is estimated, interpolated, or invented.

## Structure

```
paper_figures/
  fig01_dataset.py, fig02_performance.py, fig03_ablation.py,
  fig05_calibration.py, fig07_significance.py, fig08_external.py,
  fig09_computational.py, fig10_architecture.py, fig11_error_analysis.py
  output/                          <- ConvNeXt-Tiny results (primary)
  make_all.py                      <- rebuilds everything above

  resnet50_supplementary/
    fig02_performance_resnet50.py, fig04_reliability_mechanism_resnet50.py,
    fig05_calibration_resnet50.py, fig06_robustness_resnet50.py,
    fig07_significance_resnet50.py, fig08_external_resnet50.py,
    fig09_computational_resnet50.py, fig11_error_analysis_resnet50.py
    output/                        <- ResNet-50 + RCAF results (supplementary)
    make_all.py                    <- rebuilds the supplementary set
```

**Framing for the paper: "here is what we did" is the top-level (ConvNeXt-
Tiny) set. "We also tried ResNet-50 and here is what we got, including the
published RCAF baseline" is `resnet50_supplementary/`, reported separately.**
Nothing is mixed within a single figure — no figure in the top-level set
contains a ResNet-50 or RCAF number, and vice versa.

## Reproduce

```bash
cd paper_figures && python make_all.py                        # primary (ConvNeXt-Tiny)
cd resnet50_supplementary && python make_all.py                # supplementary (ResNet-50 + RCAF)
```

Each figure produces `output/png/*.png` (300 dpi), `output/pdf/*.pdf` and
`output/svg/*.svg` (vector), and `output/captions/*.txt` — the caption text is
generated by the same script that made the figure, with numbers computed
inline, not typed by hand.

## Why the two sets are not the same nine figures

ConvNeXt-Tiny was only ever trained for `lesion_mil`, `mr_mil` and `der_mil`.
**RCAF was never trained on ConvNeXt-Tiny** (only on ResNet-50), so no
ConvNeXt figure can include it. Two analyses were also **only ever run on the
ResNet-50 checkpoint** and have no ConvNeXt equivalent to build without a new
GPU run:

| Only exists for ResNet-50 | Why |
|---|---|
| Reliability-mechanism analysis (Fig. 4 in the supplementary set) | The corrected reliability↔counterfactual-influence pass was computed once, on the ResNet-50 `hires` checkpoints, and never re-run on ConvNeXt |
| Robustness suite (Fig. 6: mask degradation, frame removal, mask-shuffle, permutation invariance) | Same — computed only for the ResNet-50 `hires` run |

These two are filed under `resnet50_supplementary/` only, honestly labelled,
rather than duplicated or approximated for ConvNeXt.

The TN5000 external-validation figures also differ in scope for a real
reason: **only `der_mil` was adapted and evaluated on TN5000 with ConvNeXt-
Tiny** — `mr_mil` and `lesion_mil` were not. And TN5000 ships pixel-level
masks for **0 of 5000 images**, so the ConvNeXt "pixel-mask" arm silently
received the same bounding-box input as the "bbox" arm; `fig08_external.py`
(primary) reports this honestly as a same-configuration variance measurement
rather than a genuine second mask type. The ResNet-50 supplementary version
of this figure has richer TN5000 coverage (both models, both real mask
arms, plus the label-free adaptation ladder) because that data collection
was more extensive on that backbone.

## What is not built anywhere (neither set)

No raw ThyroidXL/TN5000 pixel data, saved attention weights, or model
embeddings exist in this local environment — every training and evaluation
run happened on Kaggle, and only result tables and a handful of checkpoints
were ever fetched back. So, in both the primary and supplementary sets:

- Representative ultrasound images / preprocessing / ROI crops
- Attention-MIL visualisation overlaid on actual frames
- Grad-CAM for correct/incorrect predictions
- Feature-space t-SNE / UMAP / PCA of patient or frame embeddings

are not producible from what exists locally, and are not faked with
placeholders. `fig04_reliability_mechanism_resnet50.py`'s panel (d) is the
closest real substitute: the model's own per-frame reliability score for one
real test patient, plotted from the raw per-token dump — a genuine per-frame
signal, not an image overlay.

Unlocking the four items above needs one additional Kaggle inference pass
that saves small artefacts (rendered Grad-CAM PNGs, attention alphas,
embedding vectors, a handful of representative crops) — a scoped CPU/GPU job,
not a retraining run — which has not been launched.
